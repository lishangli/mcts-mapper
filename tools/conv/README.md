# conv2d_3x3 timed driver

`main_conv_timed.c` is the conv2d_3x3 benchmark driver with `rdcycle` around
`cgra_execute0`, used to measure the convolution layer's throughput:

```
CONV_PERF cycles=178
42/42 defined outputs bit-exact (transposed tap order, see tools/s2/check_conv2d.py)
3528 ops / 178 cycles = 19.8 ops/cycle = 31 % of the 64 ops/cycle array ceiling
```

Build (needs the FDRA tree and the riscv toolchain):

```bash
cd tools/conv
RISCV=.../riscv64-unknown-elf-gcc-8.3.0-2020.04.1-x86_64-linux-ubuntu14
T=.../generators/fdra/software/tests
$RISCV/bin/riscv64-unknown-elf-gcc -DPREALLOCATE=1 -DMULTITHREAD=1 -mcmodel=medany \
  -std=gnu99 -O2 -ffast-math -fno-common -fno-builtin-printf -march=rv64gc \
  -I. -I$T/riscv-tests -I$T/riscv-tests/env -I$T -I$T/include \
  -I$T/riscv-tests/benchmarks/common -nostdlib -nostartfiles -static \
  -T $T/riscv-tests/benchmarks/common/test.ld -DBAREMETAL=1 \
  main_conv_timed.c cgra_execute_dual.c \
  $T/riscv-tests/benchmarks/common/*.c $T/riscv-tests/benchmarks/common/*.S \
  -lm -lgcc -o conv.riscv
```

`cgra_execute_dual.c` is generated by `cgra-compiler`
(`benchmarks/test4/conv2d_3x3`) and is not duplicated here.

`conv_timed_run.log` is the captured run this number comes from.
